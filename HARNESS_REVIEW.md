# Separate harness review — before test lock

Review performed as a second code/data audit pass by the implementation agent, not an independent researcher. No subagent or human review is claimed.

## Findings and fixes

- **Critical, fixed before test:** entire outcome dictionaries were initially included in LLM history. They contained expected regret and unnecessary-action scores computed with latent reliability. This disclosed information beyond observed outcomes. An explicit public history allowlist now includes only decision/action/reward/energy/failure/violation/switch/retry observations. The standalone audit rejects latent scoring keys in actual serialized prompts. Both earlier validation runs are invalid as efficacy evidence and remain saved. Offline readout training never used these history dictionaries, so its targets were unaffected.
- **Scoring crash, fixed before validation:** malformed tool actions reached an uninitialized expected-utility variable. Invalid output now consistently incurs -2 and a violation, consumes a decision and earns no completed work. Test covers full-horizon quitting and invalid output.
- **Difficulty symmetry, changed before test:** resource jobs initially had identical reward/cost ratios. Seeded per-phase values and initial energy now vary. The offline validation comparison (16 seeds/task) checks random, constant-action, constant-C and an observable heuristic; task difficulty was not adjusted by fly test performance.
- **Inference integration:** LM Studio ignored chat thinking toggle. One real profiling request exhausted 64 reasoning tokens; retained. Explicit closed reasoning prefix via local completion returned parseable JSON; frozen at 32 tokens and constrained grammar across all conditions. This unusual mode is a limitation, not hidden retries.

## Checks

1. Numeric archive read without executing scripts or extracting arbitrary paths. Matrix shape, finite nonnegative integer weights, 2952 IDs and 110677 pairs checked. Four compartment matrices sum exactly to supplied all-all matrix; interpreted row output and column input contact totals never exceed provided total outputs/inputs. Blank entries represent zero. Upstream release differences and missing archive-specific licence retained in RESEARCH.md.
2. Real rewires have exactly the same in/out degree vector and incoming strengths, identical weight/sign multiset, ten accepted swaps per edge and ~3.3–3.4% original-edge overlap. They preserve node identities at ports. Random graphs match N/M/weight multiset and identical dynamics/readout budget. Autapses and outgoing strengths are acknowledged mismatches.
3. Numerical contraction bound <=0.85, finite-state checks, zero-input decay, independent reset and reset-ablation tests. Quantified decay and timing in data/dynamics_checks.json. Persistent states are numerical engineering, not biological hunger or learning.
4. Pre-generated environmental random tables indexed by tick/action prevent action-dependent RNG consumption. All arms get the same seeded scenario. Entire episode splits and unseen exact change schedules. No wall-clock ticks or future schedule in prompts.
5. Three observations and one action opportunity per interval, six intervals per episode. Same frozen model, prompt/interface template, history availability, context/output limits. Actual token differences recorded; no hidden extra tool/LLM actions. Small controller readouts train only from training and select on validation. Four candidates per trained condition, including reset ablation.
6. Standalone audit reconstructs score arithmetic from raw records, checks full horizon, work/violation totals, exact public prompt keys, history length, call settings and absence of scoring-only telemetry. Test audit is run again after evaluation. Signed counterfactual action change is checked with paired original/neutral signals at identical observed states, not inferred from advice agreement.
7. Initial cap uses locked reservations including failed attempts. Test outputs refuse overwrite; protocol hashes checked before evaluation. Browser exploratory calls use separate log tags and never enter reported performance or tuning.

## Unresolved limitations

Six decisions are a short memory challenge and only three environment seeds per task plus three interface seeds fit the cap. Bootstrap remains descriptive. Final sanitized LLM validation checks two arms (24 calls); all seven had earlier contaminated validation and all seven controllers passed numerical tests. Low model competence or ignored advice can limit any signal. The observable heuristic is a myopic engineered teacher, not optimal planning; surrogate MSE selection may not optimize closed-loop return. Conservative recurrence scaling and dense artificial input ports may wash out anatomical advantages. True neuron signs, anatomy-specific ports and biological dynamics are unvalidated.

Resource failures reflect feasibility management; the tools' unnecessary-action metrics use the scorer's latent expected utility, excluding the future value of information. Recovery is time to next positive reward, not recovery of a globally optimal policy. Exploration overrides can make success impossible; they are not benchmark changes. Dataset-specific redistribution terms remain unclear; local research artifacts are kept local. No general biological or novelty claim is supported by this pilot.

Final fit inspection: every selected condition/seed uses leak 0.5, so graph arms match the numerical neuron parameters as well as recurrence form. Ridge penalties differ for some refitted controls; that is the outcome of equal four-candidate validation selection. Each readout also uses 32 training-derived centering/scaling constants alongside its 51 linear coefficients; this preprocessing capacity is matched across trained arms. Autapse counts differ between fly (537) and rewired graphs (51–64), a graph invariant proving the controls are not merely relabelled fly graphs.
